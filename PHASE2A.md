Build: classes-phase2a-v15.

The website needs the accompanying Apps Script update before Classes is available.
Add Classes.gs and ClassesBridge.html to the existing bound Apps Script project,
add the classes_bridge dispatch to the existing doGet, run initializeClasses,
and update the existing deployment to a new version with the same URL.

Results columns, doPost and exam engine remain unchanged.
Teacher demo login: ascap / ascap. This is development login only.
Classes additionally requires the private server-generated school access key.
Enter that key in Classes; never commit it to GitHub.

Existing local Classes are retained and can be imported individually using their
original IDs. Schedule drafts and teacher Results retrieval remain Phase 1 scaffolding.
